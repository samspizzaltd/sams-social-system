# Sam's Autonomous Social Media System

An autonomous AI-powered social media growth, content production, research, publishing, analytics, and monetization system for Sam's restaurant (halal Middle Eastern fast-food, Tbilisi, Georgia).

## Project Structure

```
sams-social-system/
├── backend/          # Node.js/Express API
├── frontend/         # React admin dashboard
├── database/         # PostgreSQL schemas & migrations
├── config/           # Business configuration & secrets
├── docs/             # Documentation
└── README.md
```

## Quick Start

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm start
```

## Database

PostgreSQL required. See `database/` for migration scripts.
